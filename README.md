Voici mon repo GitHub récapitulatif de mes 3 mois de stage au sein de l'IRD.

Ce repo sert à finetuner le modèle de Deep Learning (Vision/SAR) CROMACode sur le dataset So2Sat LCZ42
de l'évaluer, de faire du linear et du non linear probing sur celui-ci.
Mais il sert également à analyser les données que ce soit celles du jeu de données ou celles des résultats de mon modèle dans des
situations réelles, si l'on veut par exemple vérifier nos résultats et leur cohérence avec les vraies images des villes du temps
de la finalisation des données, qui correspond à l'année 2018, et qui peut être visualisé gratuitement sur Google Earth Pro.

Pour plus d'informations, je vous laisse regarder le dossier guide qui contient un fichier review_code.txt qui inclue un paragraphe de description de l'ensemble des fichiers python ainsi que des notebooks de mon repo.
